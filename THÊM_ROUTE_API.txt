=====================================================
HƯỚNG DẪN THÊM ROUTE VÀO routes/api.php
=====================================================

Tìm section Route::prefix('public') (khoảng dòng 40-50)

Thêm route này vào trong group public:

Route::get('field-clusters/{id}/availability-with-bookings', [FieldClusterController::class, 'getAvailabilityWithBookings']);


Ví dụ:
-------
Route::prefix('public')->group(function () {
    // Đã có sẵn
    Route::get('field-clusters', [FieldClusterController::class, 'publicIndex']);
    Route::get('field-clusters/{id}', [FieldClusterController::class, 'publicShow']);

    // ✅ THÊM DÒNG NÀY
    Route::get('field-clusters/{id}/availability-with-bookings', [FieldClusterController::class, 'getAvailabilityWithBookings']);

    // ... các route khác
});
